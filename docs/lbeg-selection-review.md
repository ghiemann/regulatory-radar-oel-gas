# LBEG selection review

The existing filter admits broad geothermal and geological-data stories as well as regulatory decisions. Examples in the current public dataset include a geothermal mapping tool and a general 3D subsurface model. It also admits formal decisions such as the return of a geothermal exploration permit.

Proposed treatment for later review: retain formal permits, decisions and other concrete regulatory developments; consider requiring a specific regulatory or project connection for general mapping, datasets and informational tools. Assess representative cases and agree the scope before changing thresholds. WP3 preserves the existing selection rules, including geothermal and lithium cases, and does not implement this proposal.
